# Design ideas

This folder contains proposed product and modeling designs that have not been
fully implemented. These documents describe intended behavior and validation
gates; they must not be treated as documentation of current runtime behavior.

- [Target discovery and trade research](target-discovery-system.md) — proposed
  evidence record, target theses, negotiation loop, and promotion gates.
- [Player research screen](player-research-screen.md) — staged plan for a
  league-aware player page that consolidates current evidence before adding
  historical tape, risk, or decision guidance.
