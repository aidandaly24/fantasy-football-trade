# Design ideas

This folder contains proposed product and modeling designs. Each document owns
its status and implementation boundary; an implemented decision contract does
not imply that its underlying research model has promoted.

- [Target discovery and trade research](target-discovery-system.md) — proposed
  evidence record, target theses, negotiation loop, and promotion gates.
- [Player research screen](player-research-screen.md) — staged plan for a
  league-aware player page; core roster navigation, current evidence, exact
  holding-period state, watchlist, and Trade Lab handoff are implemented, while
  news, completed-player trades, and observed tape remain staged.
- [Asset potential and forward market value](asset-potential-and-forward-value.md) —
  implemented exact-horizon decision contract plus a blocked 180/365-day
  offline experiment; defines the gates required before forward value may
  influence trades.
