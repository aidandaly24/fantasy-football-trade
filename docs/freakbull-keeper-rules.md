# Freakbull keeper rules

The National Freakbull League uses a four-candidate process to retain three players for the following season:

1. Each manager names one protected keeper. That player is retained with certainty.
2. Each manager names three additional wheel candidates.
3. A wheel selects one of those three candidates with equal odds. The selected player is not kept.
4. The other two wheel candidates are retained.

Therefore the protected player has a 100% retention probability, each wheel candidate has a 2/3 retention probability, and each manager ultimately keeps three of four nominated players.

Draft and roster models must keep current-season value separate from keeper optionality. Until a validated following-season forecast exists, the application should describe the four-candidate requirement and retention probabilities without inventing a combined keeper score.
